# علاء الدراجي — المساعد القانوني الذكي

واجهة عربية RTL مخصصة للاستخدام الشخصي للمحامي **علاء الدراجي**.

## النسخة الحالية

- تصميم أسود وذهبي فاخر ومهيأ للموبايل.
- التخصصات: المدني، الجزائي، الشرعي الجعفري.
- الأدوات: كتابة لائحة، تحليل قضية، لائحة تمييزية، قضاء الموظفين.
- بدون تسجيل دخول وبدون شريط تنقل سفلي.
- كل بطاقة تفتح مساحة عمل خاصة بها وجاهزة للربط بالذكاء الاصطناعي.
- مفتاح خدمة الذكاء الاصطناعي لن يوضع داخل كود الواجهة؛ الربط سيكون عبر Backend آمن.

## الملفات

- `index.html` — هيكل الواجهة.
- `styles.css` — التصميم والاستجابة للموبايل.
- `app.js` — التفاعل وواجهات الأدوات.
