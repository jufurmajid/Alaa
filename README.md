# علاء الدراجي — المساعد القانوني الذكي

واجهة عربية RTL مخصصة للاستخدام الشخصي للمحامي **علاء الدراجي**.

## النسخة الحالية

- تصميم أسود وذهبي فاخر ومهيأ للموبايل.
- التخصصات: المدني، الجزائي، الشرعي الجعفري.
- الأدوات: كتابة لائحة، تحليل قضية، لائحة تمييزية، قضاء الموظفين.
- بدون تسجيل دخول وبدون شريط تنقل سفلي.
- كل خيار يفتح مساحة عمل خاصة به ومربوط بنفس مسار الذكاء الاصطناعي مع تعليمات متخصصة لكل أداة.
- النتائج تظهر داخل الموقع ويمكن نسخها وبدء طلب جديد.
- مفتاح خدمة الذكاء الاصطناعي محفوظ في متغير بيئة على الخادم ولا يوضع داخل كود المتصفح أو المستودع.

## ربط الذكاء الاصطناعي

تمت إضافة المسار:

`/api/ai`

وهو يستخدم متغير البيئة:

`OPENAI_API_KEY`

ويمكن اختيار الموديل اختيارياً عبر:

`OPENAI_MODEL`

إذا لم يتم تحديد موديل، يستخدم الخادم `gpt-5.6`.

الطلب يرسل النص فقط حالياً. واجهة رفع المستندات موجودة، لكن قراءة محتوى PDF والصور ستُفعّل في مرحلة المستندات القادمة.

> ملاحظة: المخرجات مسودات مساعدة للمحامي وتحتاج إلى مراجعة الوقائع والمراجع القانونية قبل اعتمادها.

## الملفات

- `index.html` — هيكل الواجهة.
- `styles.css` — التصميم والاستجابة للموبايل.
- `app.js` — التفاعل وربط الأدوات بالـ API.
- `api/ai.js` — نقطة الربط الآمنة مع الذكاء الاصطناعي.
- `.gitignore` — يمنع رفع ملفات مفاتيح البيئة المحلية.
