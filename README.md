# علاء الدراجي — المساعد القانوني الذكي

موقع عربي RTL مخصص للاستخدام الشخصي للمحامي **علاء الدراجي**، بتصميم أسود وذهبي وبنية AI-first.

## ما هو جاهز

- واجهة موبايل فاخرة بدون تسجيل دخول وبدون شريط تنقل سفلي.
- التخصصات: **المدني، الجزائي، الشرعي الجعفري**.
- الأدوات الأساسية: **كتابة لائحة، تحليل قضية، لائحة تمييزية، قضاء الموظفين**.
- أداة مستقلة باسم **الدفوع المنتجة** لاستخراج الدفوع المؤثرة وترتيبها حسب القوة والأولوية والأثر، مع بيان ما يلزم لإثباتها والرد المتوقع من الخصم.
- أداة مستقلة باسم **مبادئ تمييزية**: يحدد المحامي نوع البحث **مدني / شرعي-أحوال شخصية / جزاء** ثم يكتب الواقعة أو الحدث، ويبحث النظام في مبادئ محكمة التمييز الاتحادية المنشورة على الموقع الرسمي لمجلس القضاء الأعلى، ثم يطابق أقرب المبادئ مع الواقعة ويعرض رقم القرار وتاريخه وجهة الإصدار والرابط الرسمي.
- أداة المبادئ التمييزية لا تنشئ أرقام قرارات من الذاكرة؛ إذا لم تجد مطابقة موثوقة تصرح بذلك بدلاً من اختلاق سابقة.
- كل أداة لها حقول مخصصة وتعليمات قانونية متخصصة.
- متابعة النتيجة بطلبات مثل: «قوّي الحجج»، «اختصر»، «أعد الصياغة».
- نسخ النتيجة وحفظها كنص.
- رفع PDF وDOCX وODT وExcel/CSV والصور والملفات النصية، وتحويل المستندات إلى نص داخل Cloudflare قبل التحليل.
- PWA قابلة للتثبيت عند النشر على HTTPS.
- لا توجد قاعدة بيانات للقضايا في النسخة الحالية.

## النسخة المجانية المعتمدة

الإنتاج يعمل على **Cloudflare Workers + Workers AI**، لذلك لا يحتاج المشروع إلى مفتاح OpenAI أو Groq.

- الاستضافة: Cloudflare Workers + Static Assets.
- الذكاء الاصطناعي: `@cf/google/gemma-4-26b-a4b-it` عبر Workers AI binding باسم `AI`.
- المستندات: `env.AI.toMarkdown()` لاستخراج المحتوى من PDF وWord والجداول والصور قبل إرساله للنموذج.
- مسار الذكاء الاصطناعي العام: `POST /api/ai`.
- مسار البحث في المبادئ التمييزية: `POST /api/principles`.
- المصدر القضائي لأداة المبادئ: موقع **مجلس القضاء الأعلى العراقي / مبادئ محكمة التمييز الاتحادية**.

المشروع مضبوط في `wrangler.jsonc`، وملفات الخادم والمصدر محجوبة عن النشر كملفات عامة عبر `.assetsignore`.

## النشر على Cloudflare من GitHub

1. افتح **Workers & Pages** في Cloudflare.
2. اختر **Create application** ثم **Import a repository**.
3. اختر المستودع `jufurmajid/Alaa` والفرع `main`.
4. اترك Deploy command الافتراضي: `npx wrangler deploy`.
5. احفظ وانشر.

وجود `wrangler.jsonc` يجعل Cloudflare يقرأ Worker وStatic Assets وWorkers AI binding من المشروع مباشرة.

## التشغيل المحلي

لمشاهدة الواجهة محلياً في Termux:

```bash
npm start
```

ولتشغيل بيئة Cloudflare المحلية عبر Wrangler:

```bash
npm install
npm run dev
```

> المخرجات مسودات مساعدة للمحامي، ويجب مراجعة الوقائع والمراجع القانونية قبل اعتمادها.

## الملفات الأساسية

- `index.html` — الواجهة الرئيسية.
- `styles.css` و`polish.css` — التصميم والتشطيبات.
- `app.js` و`polish.js` — التفاعل والنتائج والمتابعة والمرفقات.
- `defenses.js` — أداة الدفوع المنتجة المستقلة.
- `principles.js` — واجهة أداة المبادئ التمييزية المستقلة وربطها بمسار البحث.
- `src/worker-v2.js` — Cloudflare Worker والذكاء الاصطناعي وتحويل المستندات والبحث في المصدر القضائي الرسمي.
- `wrangler.jsonc` — إعداد Cloudflare Workers وWorkers AI وStatic Assets.
- `.assetsignore` — يمنع ملفات الخادم والمصدر من الظهور كملفات عامة.
- `manifest.webmanifest` و`sw.js` — دعم PWA.
