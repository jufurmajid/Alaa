# علاء الدراجي — المساعد القانوني الذكي

موقع عربي RTL مخصص للاستخدام الشخصي للمحامي **علاء الدراجي**، بتصميم أسود وذهبي وبنية AI-first.

## ما هو جاهز الآن

- واجهة موبايل فاخرة مستوحاة من التصميم المتفق عليه.
- بدون تسجيل دخول وبدون شريط تنقل سفلي.
- التخصصات القضائية: **المدني، الجزائي، الشرعي الجعفري**.
- الأدوات: **كتابة لائحة، تحليل قضية، لائحة تمييزية، قضاء الموظفين**.
- كل خيار يفتح مساحة عمل مختلفة بحقوله المناسبة، وليس نموذجاً عاماً واحداً.
- جميع الأدوات ترسل إلى محرك ذكاء اصطناعي واحد مع تعليمات متخصصة لكل قسم.
- إمكانية متابعة نتيجة الذكاء الاصطناعي بطلب مثل: «قوّي الأسباب» أو «اختصر الصياغة».
- نسخ النتيجة أو حفظها كملف نصي.
- دعم إرفاق مستندات وصور مع القضية: PDF، Word، RTF/ODT، Excel/CSV، PowerPoint، TXT/Markdown، JPG/PNG/WebP.
- المرفقات تُحوّل داخل المتصفح وتُرسل مع الطلب عند تشغيل الأداة، ولا توجد قاعدة بيانات للقضايا في النسخة الحالية.
- الموقع مهيأ ليعمل كتطبيق ويب قابل للتثبيت PWA عند نشره على HTTPS.

## الخصوصية والمفاتيح

مفتاح خدمة الذكاء الاصطناعي **لا يوضع داخل `app.js` ولا داخل GitHub**. يوضع فقط كمتغير بيئة على الخادم:

```text
OPENAI_API_KEY=...
```

الإعدادات الاختيارية موضحة في `.env.example`:

```text
OPENAI_MODEL=gpt-5.6-terra
OPENAI_REASONING_EFFORT=medium
OPENAI_MAX_OUTPUT_TOKENS=6000
```

الطلبات إلى OpenAI تستخدم `store: false`، والموقع نفسه لا يخزن القضايا في قاعدة بيانات.

## تشغيل المشروع على أي استضافة Node لاحقاً

المشروع لا يعتمد على Vercel أو Cloudflare. تمت إضافة خادم Node بدون أي مكتبات خارجية، لذلك يبقى اختيار الاستضافة مفتوحاً.

```bash
npm start
```

الخادم يشغّل الموقع ويقدم مسار الذكاء الاصطناعي نفسه:

```text
POST /api/ai
```

يوجد أيضاً `api/ai.js` كـ adapter اختياري للاستضافات التي تدعم serverless functions.

## حدود المرفقات في الواجهة الحالية

للحفاظ على سرعة الاستخدام من الهاتف وسهولة نقل المشروع بين الاستضافات، الواجهة تحدد حالياً:

- حتى 4 ملفات في الطلب الواحد.
- حتى 8 MB للملف الواحد.
- حتى 10 MB كمجموع للملفات في الطلب الواحد.

يمكن رفع هذه الحدود لاحقاً بحسب الاستضافة النهائية.

## الملفات الأساسية

- `index.html` — الواجهة الرئيسية ومساحة عمل الأدوات.
- `styles.css` — الهوية السوداء والذهبية والاستجابة للموبايل.
- `app.js` — النماذج الديناميكية، المرفقات، الطلبات، المتابعة، النسخ والحفظ.
- `lib/ai-core.mjs` — تعليمات الذكاء الاصطناعي، قراءة مدخلات الملفات والمنطق المشترك.
- `server.mjs` — خادم Node محمول لتشغيل الموقع والـ API معاً.
- `api/ai.js` — adapter لمسار API على استضافات serverless المتوافقة.
- `manifest.webmanifest` و `sw.js` — دعم PWA والعمل بالواجهة عند ضعف/انقطاع الاتصال.
- `.env.example` — أسماء متغيرات البيئة فقط من دون أي أسرار.

> المخرجات مسودات مساعدة للمحامي، ويجب مراجعة الوقائع والمراجع القانونية قبل اعتمادها.
